# 坦克大战 GAME DESIGN DOCUMENT

本文件是全部数值与规则的唯一权威来源（single source of truth）。所有数值必须集中定义在 `Data/GameConfig.swift`，代码中禁止出现魔法数字。改数值只改这份文档和 `GameConfig.swift`。

---

## 1. 基础规格

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 平台 | iOS 16.0+ | SpriteKit + Swift，SwiftUI 承载 |
| 屏幕方向 | 竖屏锁定 | 只勾选 Portrait |
| 战场网格 | 13 x 13 tile | 经典 Battle City 规格 |
| tile 尺寸 | 16 pt | |
| 战场逻辑尺寸 | 208 x 208 pt | `scaleMode = .aspectFit` |
| 目标帧率 | 60 fps | |
| 对齐粒度 | 8 pt（半 tile） | 坦克转向时垂直轴吸附到 8 的整数倍 |

### 布局（竖屏）

```
+---------------------------+
|  HUD  命数 / 关卡 / 敌人数  |  高 44 pt
+---------------------------+
|                           |
|      战场 208 x 208        |  正方形，水平居中
|                           |
+---------------------------+
|                           |
|  摇杆(左)      射击键(右)   |  控制区，占剩余空间
|                           |
+---------------------------+
```

战场缩放比例 = `min(safeWidth / 208, availableHeight / 208)`，保证在 iPhone SE 到 Pro Max 上都完整可见且不变形。

### 坐标系约定

- 网格坐标 `GridPoint(col, row)`，`col` 从左到右 0...12，`row` 从上到下 0...12
- SpriteKit 场景坐标原点在左下角，因此转换公式固定为：
  - `x = CGFloat(col) * 16 + 8`
  - `y = 208 - (CGFloat(row) * 16 + 8)`
- 所有涉及行列与像素互转的地方必须调用 `GridMap.center(of:)` / `GridMap.gridPoint(at:)`，禁止就地手写公式

## 2. 地形

关卡用 13 行字符串定义，每行 13 个字符。字符映射：

| 字符 | 地形 | 坦克通行 | 子弹穿过 | 备注 |
| --- | --- | --- | --- | --- |
| `.` | 空地 | 可 | 可 | |
| `B` | 砖墙 | 否 | 否，子弹销毁并破坏砖墙 | 任意等级子弹可摧毁 |
| `S` | 钢墙 | 否 | 否，子弹销毁 | 仅火力 Lv3 子弹可摧毁 |
| `W` | 河流 | 否 | 可 | 有水波动画 |
| `G` | 草丛 | 可 | 可 | 渲染在坦克之上作为视觉遮蔽 |
| `I` | 冰面 | 可 | 可 | 松开摇杆后滑行 0.35 秒 |
| `E` | 基地（老鹰） | 否 | 否，被击中即败北 | 每关唯一，固定在 `(6, 12)` |
| `P` | 玩家出生点 | — | — | 渲染为空地，默认 `(4, 12)` |
| `1` `2` `3` | 敌方出生点 | — | — | 渲染为空地，通常在顶部 |

砖墙破坏粒度：第一阶段为整 tile 破坏。阶段 7 可选升级为 2x2 子块（8 pt）逐块破坏，`BrickTile` 需预留 `damageMask: UInt8` 字段以便平滑升级。

冰面滑行：进入冰面后，输入中断时坦克继续以当前速度移动，`0.35` 秒内线性衰减到 0；滑行过程中撞墙立即停止。

## 3. 玩家坦克

| 属性 | 取值 |
| --- | --- |
| 尺寸 | 16 x 16 pt（1 tile） |
| 初始命数 | 3 |
| 移动速度 | 48 pt/s（3 tile/s） |
| 复活无敌 | 3.0 秒（闪烁） |
| 出生点 | 关卡中的 `P` |

### 火力等级

星星道具累加，上限 Lv3。**玩家死亡后火力等级立刻归 0**，护盾、僵直等所有临时状态一并清除；命数与已通关进度不受影响。这是本作的核心惩罚机制。

| 等级 | 同屏子弹数 | 子弹速度 | 特性 |
| --- | --- | --- | --- |
| Lv0 | 1 | 120 pt/s | 可摧毁砖墙 |
| Lv1 | 1 | 144 pt/s | 子弹更快 |
| Lv2 | 2 | 144 pt/s | 可连续发射 2 发 |
| Lv3 | 2 | 144 pt/s | 可摧毁钢墙 |

### 移动手感规则（关键）

1. 只支持 4 向移动（上/下/左/右），不支持斜向
2. 摇杆输入向量取绝对值较大的轴作为方向，避免抖动
3. 转向时，垂直于新方向的坐标轴吸附到最近的 8 pt 倍数，让坦克能顺畅进入 tile 间的走廊
4. 移动使用自研 AABB 检测：先计算候选位移，与网格中的阻挡 tile 及其他坦克求交，有交则把位移裁剪到刚好贴合，绝不允许穿透后再弹回
5. 坦克之间互相阻挡，不允许重叠

## 4. 敌方坦克

同屏敌人上限固定为 **3 台**（对应「对面有三个坦克」）。每关有 `totalEnemies` 总量，场上少于 3 台且还有余量时，出生点在 1.5 秒闪烁后生成新敌人。

| 类型 | HP | 速度 | 子弹速度 | 分值 | 行为特点 |
| --- | --- | --- | --- | --- | --- |
| 普通型 Normal | 1 | 40 pt/s | 84 pt/s | 100 | 均衡 |
| 快速型 Fast | 1 | 72 pt/s | 84 pt/s | 200 | 移动快，转向频繁 |
| 装甲型 Armored | 4 | 32 pt/s | 84 pt/s | 400 | 每次受击换色：绿→黄→灰→红 |

「敌方坦克有若干条命」通过两个层面实现：装甲型自身有 4 点 HP 需多次命中；同时整关有 `totalEnemies` 的补充队列，击毁一台会补一台，形成持续压力。

### AI 状态机

`AIController` 每 `0.5` 秒做一次决策，状态：

- `patrol` 巡逻：随机选择可通行方向，遇墙或到达路口重新决策，权重偏向"朝下"
- `huntBase` 攻基地：用 BFS 在网格上求到基地的最短路径，沿路径前进；遇砖墙则停下开火轰开
- `huntPlayer` 追玩家：BFS 求到玩家的路径，距离玩家 6 tile 内启用
- `evade` 规避：检测到同轴且 3 tile 内有玩家子弹飞来时，垂直方向移动一格

状态权重：`patrol 20% / huntBase 40% / huntPlayer 40%`，`evade` 为条件触发的抢占状态。距离玩家 6 tile 内且同轴时立即开火，开火冷却 `1.2` 秒（快速型 `0.9` 秒）。

BFS 每帧最多执行 1 次、结果缓存 0.5 秒，避免 3 台敌人同帧寻路造成掉帧。

## 5. 道具系统（双向效果）

**玩家和敌人都能拾取**，这是本作与经典版最大的差异。

- 生成间隔：随机 `6 ~ 12` 秒
- 生成位置：随机的空地 tile，不得与坦克、基地相邻
- 同屏上限：1 个
- 存活时间：15 秒，最后 3 秒闪烁后消失
- 谁碰到谁生效，敌方 AI 在道具 5 tile 内且路径通畅时会主动去吃

| 道具 | 玩家拾取效果 | 敌人拾取效果 |
| --- | --- | --- |
| 星星 Star | 火力等级 +1（上限 Lv3） | 该敌人子弹速度 x1.5 且子弹可穿透砖墙 |
| 头盔 Helmet | 获得 10 秒护盾，免疫一切伤害 | 该敌人 5 秒无敌，闪烁提示 |
| 坦克 Tank | 命数 +1 | 立即增援 1 台普通型（可突破同屏 3 台上限，上限临时变 4） |
| 手雷 Grenade | 清空场上所有普通敌人；对 Boss 造成 3 点伤害 | 玩家僵直 2 秒（不能移动不能开火，可被击杀） |
| 计时器 Timer | 冻结所有敌人 8 秒（可被击杀） | 冻结玩家 3 秒 |
| 铲子 Shovel | 基地围墙变钢墙 15 秒，结束前 3 秒闪烁 | 基地围墙变砖墙（若已是砖墙则清空）15 秒 |

概率权重：星星 25 / 头盔 20 / 坦克 15 / 手雷 15 / 计时器 15 / 铲子 10。Boss 关（3、6、9、10）中手雷权重降为 5，避免用手雷轻易削 Boss。

## 6. Boss 设计

Boss 关：第 3、6、9 关各一个小 Boss，第 10 关一个大 Boss。Boss 与普通敌人同场出现，Boss 存活时不计入同屏 3 台上限。

### 小 Boss（Level 3 / 6 / 9）

| 属性 | 取值 |
| --- | --- |
| 尺寸 | 32 x 32 pt（2x2 tile） |
| HP | 8 |
| 速度 | 36 pt/s |
| 分值 | 1000 |
| 免疫 | 手雷只造成 3 点伤害；不会被计时器冻结，只减速 50% |

阶段：

- 阶段 1（HP 8~5）：单发直射，开火冷却 1.0 秒
- 阶段 2（HP 4~1）：三向散射（正前方 + 左右各偏 30 度），速度 x1.3，开火冷却 0.8 秒，进入阶段时全屏闪白一次

每关小 Boss 略有差异：L3 无附加，L6 移动速度 +20%，L9 阶段 2 时每 6 秒召唤 1 台快速型。

### 大 Boss（Level 10）

| 属性 | 取值 |
| --- | --- |
| 尺寸 | 48 x 48 pt（3x3 tile） |
| HP | 20 |
| 速度 | 30 pt/s |
| 分值 | 5000 |
| 免疫 | 手雷只造成 3 点伤害；免疫计时器冻结；碾压砖墙前进 |

三阶段：

- 阶段 1（HP 20~14）散射形态：三向散射，开火冷却 1.0 秒，只做水平巡逻
- 阶段 2（HP 13~7）冲撞形态：锁定玩家所在行/列后蓄力 0.8 秒，以 90 pt/s 直线冲撞，碾碎路径上的砖墙，撞到玩家造成致死伤害；撞墙后眩晕 1.5 秒（此时受到 2 倍伤害）
- 阶段 3（HP 6~1）狂暴形态：每 10 秒召唤 2 台快速型；每 4 秒发射 8 向环状弹幕；保留冲撞

顶部显示 Boss 血条，分段显示（每 1 HP 一格），换阶段时血条变色 + 屏幕抖动 0.4 秒。

## 8. 胜负与流程

- 通关条件：`totalEnemies` 全部击毁且 Boss（若有）已击毁
- 失败条件（任一）：基地被击中 / 玩家命数耗尽
- 失败后从当前关重新开始，火力归 0，命数重置为 3
- 关卡过渡：显示 `STAGE N`、得分统计 2 秒后进入下一关
- 存档：`UserDefaults` 记录 `maxUnlockedLevel`、`highScore`；主菜单可选择已解锁关卡

## 10. 美术规范

- 单 tile 素材 16 x 16 px，坦克 16 x 16 px，小 Boss 32 x 32 px，大 Boss 48 x 48 px
- 全部使用 `texture.filteringMode = .nearest`，禁止任何抗锯齿缩放
- 调色板限制为 16 色，风格参考 NES
- 阶段 1-6 用 `SKTexture` 由代码生成的纯色/简单图案占位；阶段 7 统一替换为 texture atlas，替换时不得改动任何游戏逻辑代码
- 占位色：玩家黄色、普通敌人灰白、快速型青色、装甲型绿色、Boss 红色、砖墙棕色、钢墙浅灰、河流蓝色、草丛深绿、冰面淡蓝
